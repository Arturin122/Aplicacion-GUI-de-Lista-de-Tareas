# Aplicación GUI Lista de Tareas

Aplicación desarrollada en Python utilizando Tkinter para gestionar tareas.

## Funcionalidades

- Añadir tareas
- Marcar tareas como completadas
- Eliminar tareas
- Uso de eventos (Enter y doble clic)

## Requisitos

- Python 3.x

## Ejecución

```bash
python app_tareas.py
